# key learnings and things to remember

## fastapi: The web framework for my REST endpoints
## uvicorn: Runs the FastAPI app locally (Vercel runs it for me in production)
## psycopg: The Python driver that talks to Postgres (Neon)
## python-dotenv: Loads DATABASE_URL from my .env file
## email-validator: Checks email format (FastAPI's EmailStr type needs it)
